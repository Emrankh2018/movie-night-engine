# Data and artwork rights — prototype only

All 24 movie records are deliberately fictional. Titles, English/Arabic hooks, year, runtime, genres, content notes and fit tags are original development fixtures. Their provenance is `synthetic`, their source URL lists are empty and review is a **fixture audit only**. No real facts have been verified and no founder editorial approval is implied.

Availability belongs to imaginary providers, carries no source/destination URL and can only display as simulated. It is never evidence of a film being on a real platform. Real provider names appear only to explain unsupported filtering.

Artwork consists of original vector geometry, typography and CSS colours. Outfit and Noto Sans Arabic are self-hosted with their SIL OFL licenses included under `public/fonts`; provenance is documented in UI_DIRECTION.md. No third-party posters, clips, cover images, scraped text or remote runtime font assets are included.

The local source has no real-data adapter. TMDB, Wikidata imports, Watchmode, IMDb, OMDb and unofficial provider endpoints are not integrated. Before adding any real catalog, document allowed fields, source URL, retrieval date, license category, review state, reviewer and any retention/attribution requirements. Image rights require independent records.

M2 gate: Emran approves editorial content; rights are documented; Qatar provider evidence is checked with permitted access and expires within seven days. Record country, service, access type, source, timestamp and reviewer. Unknown or expired evidence remains unknown. The source report's provider pricing/legal notes are planning references, not independently reverified by this implementation.
